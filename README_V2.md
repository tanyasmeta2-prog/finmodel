## Текущее состояние

Расчет A–E обновлён по методике МП и замечаниям СЭО по ЭП. Версия использует отдельные пути сохранения:
- локальные проекты: `talan_model_saves_v2`;
- последний открытый проект: `talan_model_last_opened_v2.json`;
- проекты на Яндекс Диске: `app:/projects_v2`.

Исходные проекты не копируются автоматически. Для переноса можно выгрузить заполненный шаблон из исходной версии и загрузить его в Версию 2.

## Согласованный объем следующих изменений

- Изменения методики МП и ЭП — только статьи A–E.
- G, паркинги и инфраструктура — действующая схема расчета до уточнения со сметчиками. Новые базы наружных работ и правила исключения площадей не внедрять.
- Суммы G, Z и генподряда, расшифровка косвенных расходов в выгрузке и маркировка полей сметчика — изменения представления без пересмотра методики G и инфраструктуры.
- Неясные нормативы не применять автоматически без уточнения.

## План корректировок — B20.10 (25.11.2026)

Статус: запланировано; в расчет пока не внедрено.

Предусмотреть два взаимоисключающих режима расчета статьи B20.10:

1. **Укрупненный** — площадь фасада × комплексная ставка на 1 м² фасада. Единственная база объема — площадь фасада; разбивка по элементам для этого режима не требуется.
2. **Детальный** — сумма стоимости элементов (объем каждого элемента × его ставка). Для каждого обязательного элемента предусмотреть статус: **«рассчитан / не требуется / нет данных»**.

В детальном режиме отсутствие данных не приравнивать к отсутствию работ. При статусе «нет данных» показывать неполноту статьи; частичную сумму не представлять как полный расчет B20.10. Укрупненную сумму и сумму детализации одновременно не начислять.

## Реализовано

- МП: A10/B30 по застройке, A20 по застройке секций, B10 по надземной площади, B20 по фасаду (3,0 м, исключены сблокированные торцы), E20 по числу секций; остальные статьи второго уровня по ПП. Стилобат — отдельная непересекающаяся строка.
- ЭП: отдельные строки кладки и отделки по типам фасадов, ограждения м², корзины/экраны шт., входные группы по площади или за штуку при отсутствии площади, террасы первого/верхних этажей.
- Двери квартир по квартирам; МОП/техпомещения/входные группы по проёмам. ИТП/котельная по комплектам на этап. Мебель МОП по площади холла.
- Раздельные ставки стадий, аналог, дата цен, состав работ. «Не требуется» — явное исключение статьи, без стирания введённой ставки.
- Итоги G и Z по каждой строке и отдельный итог генподряда внутри Z. Формулы и базы G/паркингов/инфраструктуры сохранены.
- В Excel — состав косвенных расходов (включая землю, благоустройство, инфраструктуру и прочие существующие категории), детализация инфраструктуры по блокам, формулы A–E и детализация G/Z.
- Жёлтая маркировка полей СЭО, голубые проектные объёмы, серые формулы. Проверки неполного расчёта и архив старых ставок с изменившимися единицами.
- Импорт/экспорт шаблонов включает геометрию МП, ставки обеих стадий и детализацию ЭП. Прежняя единая ставка МП остаётся только для справки при переносе и не участвует в новой методике.

## Проверка

`python -m pytest tests/test_methodology_v2.py -q`

Проверяются геометрия, детализация, двери и ИТП, однократное применение сценария, перенос Excel и неизменность кода расчёта G, паркингов и инфраструктуры относительно базовой Версии 2.
