# Конфигуратор — Версия 2

Рабочая копия исходной финмодели для последовательной проверки доработок.
Базовый коммит main: d5e5aa583967d5ef733380f4540974a1e65b5a96.

## Текущее состояние

Расчетные функции сохранены без изменений. Добавлены метка версии и отдельные пути сохранения:
- локальные проекты: `talan_model_saves_v2`;
- последний открытый проект: `talan_model_last_opened_v2.json`;
- проекты на Яндекс Диске: `app:/projects_v2`.

Исходные проекты не копируются автоматически. Для переноса можно выгрузить заполненный шаблон из исходной версии и загрузить его в Версию 2.

## Согласованный объем следующих изменений

- Изменения методики МП и ЭП — только статьи A–E.
- G, паркинги и инфраструктура — действующая схема расчета до уточнения со сметчиками. Новые базы наружных работ и правила исключения площадей не внедрять.
- Суммы G, Z и генподряда, расшифровка косвенных расходов в выгрузке и маркировка полей сметчика — изменения представления без пересмотра методики G и инфраструктуры.
- Неясные нормативы не применять автоматически без уточнения.

Эти доработки в исходную копию пока не внесены.

## Запуск

```bash
pip install -r requirements.txt
streamlit run app.py
```

Для отдельного веб-приложения Streamlit выбрать репозиторий `tanyasmeta2-prog/finmodel`, ветку `configurator-v2`, файл `app.py`. Настройки исходного развертывания не менять.
